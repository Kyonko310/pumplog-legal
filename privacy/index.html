広告に関する情報

PUMPLOGのiPhone版には、広告配信のためGoogle Mobile Ads SDKが組み込まれています。同SDKは、広告の配信状況、端末設定、地域、同意状況その他の条件に応じて、次の情報を処理する可能性があります。これは、すべての情報が常に取得されることを意味するものではありません。

  • IPアドレスおよびIPアドレス等から推定されるおおまかな位置情報
  • 広告識別子（利用可能な場合）その他の端末、アプリまたは開発者に関連付けられた識別子
  • 表示された広告、広告への反応その他の広告関連情報
  • クラッシュログ、診断情報およびパフォーマンス情報
  • アプリの起動、タップ、広告との操作などの利用情報

3. 外部サービス

Supabase

PUMPLOGは、バックエンド、認証およびデータベースとしてSupabaseを利用しています。情報はサービス提供に必要な範囲でSupabaseを通じて処理されます。

Google AdMobおよびGoogle User Messaging Platform

PUMPLOGのiPhone版では、タイムライン画面にバナー広告を表示するため、Google AdMobを導入しています。

AdMob側の審査・配信制限、広告在庫、通信状態、地域または同意状況等により、広告が表示されない場合があります。この場合も、広告SDKはアプリに組み込まれています。

PUMPLOGは、広告配信にGoogle AdMob（Google Mobile Ads SDK）を、地域や法令等に応じた同意管理にGoogle User Messaging Platform（UMP）を利用します。広告リクエストや同意情報の確認に必要な範囲で、前記の広告に関する情報がGoogle LLCおよび広告配信に関与する事業者へ送信され、各事業者のポリシーに基づいて処理される場合があります。PUMPLOGは、メールアドレス、プロフィール、トレーニング記録、投稿またはコメントを広告配信用のユーザー情報として広告SDKへ渡しません。

PUMPLOGは、広告リクエスト時に非パーソナライズ広告の指定を行います。非パーソナライズ広告は過去の行動に基づいて選択されませんが、現在のアプリ内容やおおまかな地域等の文脈情報が使用される場合があります。また、この指定は情報の処理や追跡が一切行われないことを意味するものではなく、広告配信、表示回数の調整、集計レポート、効果測定、不正利用防止およびSDKの品質改善等のため、端末識別子、広告データ、利用情報または診断情報等が処理される可能性があります。

PUMPLOGは、iOSのApp Tracking Transparency（ATT）を通じて、広告識別子を広告の表示回数の調整と広告効果の測定に使用することについて許可を求めます。利用者がATTを許可した場合、広告識別子（IDFA）が利用可能となり、Google Mobile Ads SDKにより広告リクエスト等で処理される可能性があります。ATTを拒否または制限した場合、Google Mobile Ads SDKはIDFAを広告リクエストに送信しないとされていますが、IPアドレス、IDFA以外の端末・アプリ関連識別子、広告データ、利用情報および診断情報等が処理される可能性があります。ATTの選択はiOSの設定から変更できます。

広告に関する同意と選択の変更

アプリ起動時には、UMPを通じて同意情報を更新し、地域や法令等に応じて必要な場合に同意画面を表示します。UMPが広告リクエストを許可し、かつATTの状態が許可、拒否または制限のいずれかとして確認できた場合に限り、広告をリクエストします。ATTが未決定または確認できない場合、もしくはUMPが広告リクエストを許可しない場合は広告を表示しません。ATTを拒否または制限した場合でも、UMPが広告リクエストを許可しているときは、IDFAを使用しない形で広告が表示される場合があります。

利用者は、UMPが変更用の導線を必要と判定した場合、アプリの設定画面に表示される「広告プライバシー設定」から選択を確認または変更できます。地域や同意状態によって、この項目が表示されない場合があります。同意状態が変更された場合、PUMPLOGは広告を表示できるかを再確認し、条件を満たさない場合は広告を表示しません。

Googleによる情報の取り扱いについては、Google プライバシーポリシー、Googleのサービスを使用するサイトやアプリから収集した情報の使用およびGoogle Mobile Ads SDKのデータ開示資料をご確認ください。

4. 通報と安全対策

通報時には、対象内容を適切に確認するため、通報理由、利用者が入力した詳細説明、投稿・コメント・プロフィール等のcontent snapshot（通報時点の内容）を保持する場合があります。不正利用防止、紛争対応、安全性確保のため、通報記録や関連情報を必要な一定期間保持する場合があります。

5. 情報の保護

運営は、取り扱う情報への不正アクセス、漏えい、改ざん等を防ぐため、サービスの性質に応じた安全管理に努めます。

6. アカウントと情報の削除

利用者はアプリ内からアカウントを削除できます。アプリを利用できない場合は、アカウント削除ページから削除申請を開始できます。

削除時は、アカウント、プロフィール、トレーニング、投稿、コメント等を削除対象とします。利用者がグループを所有している場合、対象グループの確認と利用者による明示的な確認を経て、所有グループを削除してからアカウント削除へ進みます。グループ削除により、そのグループと関連データが他のメンバーからも利用できなくなる場合があります。ただし、法令遵守、安全対策、不正利用防止、紛争対応その他正当な理由がある場合、一部情報を必要な期間保持する場合があります。保持期間は保持の目的、必要性、調査状況および適用法令等により異なるため、一律の期間は定めていません。Googleその他の外部事業者へ送信された情報の保持および削除には、各事業者のポリシーも適用されます。

7. 本ポリシーの変更

機能や情報の取り扱いが変わる場合、本ポリシーを更新します。重要な変更がある場合は、アプリ内または本ページなど適切な方法で案内します。
